# Source format: 2004-05 vs 2025-26

Checked 2026-10-17 before scaling to all seasons (overnight plan, step 3).
Files: ramirobentes `pbp_regular_2005.parquet` vs `pbp_regular_2026.parquet`;
shufinskiy `shotdetail_2004` vs `shotdetail_2025`.

## Summary

| Area | 2004-05 | 2025-26 | Impact on our pipeline |
|---|---|---|---|
| Column set | 61 columns | same 61 columns, same types | none |
| Rows / games | 560,364 / 1,230 | 622,187 / 1,230 | none |
| `clock` | `MM:SS` | `MM:SS.ss` (e.g. `12:00.00`, `00:00.20`) | parser accepts both; `secs_elapsed_game` keeps tenths (56,012 rows have fractional seconds) |
| `event_num` | mostly consecutive | gaps (2, 4, 8, 9, …) = cdn.nba.com `actionNumber` | none; still unique per game |
| New `msg_type` codes | — | **22** team "Heave" marker (1,099), **92** block as own row (11,912), **93** "Game End" (1,231), **95** steal as own row (20,714) | mapped to `other`; `source_msg_type` keeps the code. Confirmed by the owner 2026-10-21 (ignored by the possession code). |
| Synthetic rows | msg 99, event_num 9999 (1,297) | msg 99, event_num 9999 (2,107) | excluded + counted, same rule |
| Substitution text | `SUB: <in> FOR <out>` | `<out> replaced by <in>` | none: still player1 = out, player2 = in; lineup on the sub row is already post-sub (same as 2004-05) |
| Sub rows | 48,251 | 64,704 | more subs per game in the modern game (not a format change) |
| Jump ball roles | player1 = jumper, player2 = other jumper, player3 = player who got the tip | player1 = **player who got the tip**, player2/3 = jumpers | **player1/2/3 roles differ by era**; copied as given. Possession logic must not assume a fixed role order. Confirmed 2026-10-21: jump-ball possession is decided by the next event with a team, not by roles. |
| Blocks | blocker = `player3` on the missed shot | blocker = `player2` on the missed shot **and** a separate msg 92 row | same as above |
| Steals | stealer = `player2` on the turnover | stealer = `player2` on the turnover **and** a separate msg 95 row | steal is represented twice in 2025-26; don't double count |
| `person1type` | filled (0–7) | **all NULL** | not used by us |
| `reb_type` (off/def) | filled | **all NULL** | not used by us (derive from teams/description) |
| Extra cdn columns (`action_type`, `sub_type`, `qualifiers`, `descriptor`, `area`, `side`, `shot_distance`, `time_actual`, `official_id`, `foul_drawn_person_id`, `order`, `is_field_goal`, `shot_result`) | all NULL | filled | not used yet; available later (e.g. `foul_drawn_person_id`) |
| `locX` / `locY` | all NULL | filled for shots; **0–100 court-percentage coordinates** (e.g. 92.99, 50.0), not shotdetail's tenths of feet | **not mixed into `core.shots`**: shufinskiy shotdetail exists for every season 1996-97 → 2025-26 (regular + playoffs), so the ramirobentes fallback was never needed |
| Lineups | `"ID Name"` × 5 | same | none |
| Player keys | `"ID Name"` | same | none |
| `secs_game` range | 0 → 3,780 (3OT) | 0 → 3,480 (2OT) | none |
| Game End rows | — | 1,231 for 1,230 games (`0022500104` has 2) | `other` events, reported here |

## shufinskiy shotdetail

Same 24 columns in `shotdetail_2004` and `shotdetail_2025` (and `shotdetail_po_2025`).
2025-26: 219,160 shots vs 219,158 FGA events in ramirobentes. Check 10 detail:
219,147 joined, 13 shots without an event, 11 FGA without a shot, 5 joined shots disagree
with the event (player, team or made flag). Reported as warnings, nothing changed.

## Playoff files

- ramirobentes: `pbp_playoffs_{end_year}.parquet`, 1997 → 2026, `season_type = 'playoffs'`.
- shufinskiy: `shotdetail_po_{start_year}` (1996 → 2025), `pbpstats_po_{start_year}`.
- Play-in games (`005…` game IDs, 2020-21+) are **not** in the playoffs files. Not loaded.

## Decisions taken (conservative; confirmed by the owner 2026-10-21)

1. Map msg 22 / 92 / 93 / 95 to `other` (no new event types without the owner).
2. Keep player1/2/3 exactly as the source gives them; document that roles vary by era.
3. Never put ramirobentes `locX/locY` into `core.shots` (different coordinate system).

## Found later in the all-seasons run (other eras)

| 2014-15 | one game has lineup entries `NA <name>` (no ID; proposed 202711) | hard fail; proposed corrections only |
